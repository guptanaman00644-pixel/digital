🎨 Design Decisions & Annotations

🎨 Colour Palette

Primary blue for trust, red accent for energy, green for success.

🔤 Typography

Sora — Modern, geometric sans-serif. Weights 300–800 for hierarchy.

📐 Layout Grid

12-column CSS Grid. 2:1 split for main content and sidebar. Responsive breakpoints at 600px & 900px.

♿ Accessibility

WCAG AA contrast ratios. Semantic HTML. Keyboard navigable. Scalable font units (rem/em).

✨ Micro-interactions

Hover states on cards (translateY + shadow). Active nav underline transition. Button hover with shadow lift.

📱 Responsive Design

Mobile-first approach. Flexbox + CSS Grid. Stack to single column below 600px. Hidden nav on small screens.
